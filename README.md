# 🤖 Jarvis AI Assistant

A browser-based virtual assistant built with HTML, CSS, and JavaScript,
featuring voice and text interaction through a simple web interface.

## ✨ Features

- 🎤 Voice interaction
- ⌨️ Text-based interaction
- 💬 Interactive assistant interface
- 🌐 Browser-based application
- 🎨 Custom user interface
- 🌌 3D animated background
- 📱 Responsive web design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Web APIs
