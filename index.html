About Jarvis

Jarvis is an intelligent voice assistant that helps you with daily tasks, answers questions, and controls your browser. Built with cutting-edge web technologies, Jarvis provides a seamless and interactive experience. You can either speak your commands or type them in the text box below the voice search.

Available Commands

"Hello" / "Hi" → Greets you warmly
"What time is it?" → Tells current time
"What's today's date?" → Shows current date
"Who are you?" → Introduces itself
"Help" / "What can you do?" → Shows available features
"Open YouTube" → Opens YouTube
"Open Google" → Opens Google
"Open GitHub" → Opens GitHub
"Calculate 5 + 3" → Performs calculations
"Tell me a joke" → Tells a random joke
"Weather in [city]" → Shows weather info
"Search for [query]" → Searches the web
"Remember [something]" → Saves a note
"What did I remember?" → Retrieves saved notes
"Play music" → Opens music player
"News" → Shows latest news
"Set reminder for [time]" → Sets a reminder
"Play trivia" → Starts trivia game
"Flip a coin" → Flips a coin
"Roll a dice" → Rolls a dice
"Translate hello to Spanish" → Translates text
"Motivate me" → Gives motivational quote
